# Motor OCR de PRODUCCIÓN (dependencia OPCIONAL).

# NO hace falta para correr el andamiaje ni la suite de tests: esos usan el
# motor de plantilla, que no necesita nada más que opencv/numpy. Instala esto
# solo donde el módulo tenga que leer monitores reales (la Jetson, o dev al
# validar contra un frame real):
#
#     pip install -r ocr/requirements-motor.txt
#
# RapidOCR sobre ONNX Runtime (ADR-017): ejecuta los modelos PP-OCRv4
# exportados a ONNX. Elegido porque Paddle Inference segfaultea en la Jetson
# Orin (aarch64) mientras onnxruntime corre estable, y porque el wheel
# EMPAQUETA los modelos .onnx (det+rec+cls, ~16 MB): no descarga nada en
# runtime — apto para despliegue hospitalario sin internet.
#
# Par validado en la Jetson (env ocr-monitoreo, Python 3.10, aarch64):
# rapidocr-onnxruntime==1.4.4 con onnxruntime==1.22.1 (resuelto por pip).
# Se pinnea solo rapidocr; onnxruntime lo resuelve pip (>=1.7.0).
#
# El adaptador de PaddleOCR (ocr/motor/paddle.py) se conserva como motor
# alternativo en x86_64, pero ya no se declara aquí: quien lo quiera instala
# paddleocr/paddlepaddle a mano y lo pasa por API con motor=LectorPaddleOCR().
